Trang 1 · Mọi người, dev mới vào dự án

Giới thiệu framework

Backend dùng chung cho nhiều game mobile Unity: server là nguồn sự thật, client gửi hành động chứ không gửi kết quả; giao tiếp HTTP request–response (Protobuf cho game, JSON cho GM). Trang trình bày phạm vi P0 / P0.5 / P1 và trạng thái tại commit 175df65, cấu trúc repo, kiến trúc (sơ đồ khối, phân tầng project và luật phụ thuộc do test kiến trúc kiểm), mô hình module 2 project, mô hình “một command = một transaction” với receipt/replay và outbox, security profile, gate và giới hạn tải, lưu trữ, flavor, quan sát, Unity SDK — cùng bảng điểm mạnh kèm bằng chứng và các giới hạn hiện tại.

Thêm, bỏ, thay command

Cách dùng bộ tài liệu #

  • Mỗi file HTML tự chứa (CSS, sơ đồ SVG và script nhỏ đều nằm trong file), không tải gì từ mạng: mở offline hay gửi riêng qua email đều đọc được.
  • Đường dẫn file trong repo hiển thị dạng code; khi mở từ bản checkout của repo (thư mục docs/html/), chúng là liên kết tương đối tới file thật.
  • Số dòng “≈ dòng N” chỉ để tham khảo; tên type/method mới là tham chiếu chính.
  • Checklist ở trang 3 có cột đánh dấu, cột “Ngày / chữ ký” khi in, và mỗi nhóm bắt đầu trang mới.
