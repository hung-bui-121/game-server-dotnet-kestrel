# v0.7.0 — draft, finalized at tag

Framework `0.7.0` (unreleased). Release date: **not set** (round-close step, last section). This is the round note of the
improvement round 2026-11-03 (zh-pvp-server friction log): slices 013 consumer-readiness, 014 wire-contract, 015 config and
016 login-command, released under **one annotated tag `v0.7.0`** (research 016 R15, FR-090, FR-091). It merges the four
slice drafts, which keep the full details (every report line, test name and file:line):

- [013 consumer-readiness](../../specs/013-consumer-readiness/release-notes-draft.md)

- [015 config](../../specs/015-config/release-notes-draft.md)

Breaking-change ids are written `0NN/BC-n` (slice number / id inside that slice's draft). **The tag waits for** the combined
device session 015 T058 + 016 T069 and the Couchbase re-run ("Open manual checks").

Release rule (013, FR-051): the annotated tag of declared version `X.Y.Z` is `vX.Y.Z`; `GameServerFrameworkVersion` in
`Directory.Build.props` and `version` in `sdk/unity/com.gameserver.client/package.json` are bumped together (`VersionTests`
fails on a mismatch). Both are `0.7.0` → tag `v0.7.0`.

Full text in each slice draft.

- **013 consumer-readiness.** FG-010 three-layer Dev refusal decided by `GameServerOptions.AllowsDevProfile`

  failed start no longer throws.

  route declarations (`PlatformRoutes`, `IdentityRoutes`, …), `WireCatalog`, endpoint ↔ catalog startup check in every
  environment, `RequestOutcome().RouteName` (FG-026); `--export-wire-contract` and WireGen with deterministic,
  write-if-changed output, generated `FrameworkRoutes.cs` / `FrameworkSections.cs` in the Unity package (FG-021, FG-026 (2));

  `GameConfig` constructor and `FileGameConfigLoader.ComputeVersion(label, files)` (015/BC-6).

| Id | Change | How it surfaces | Fix |
| --- | --- | --- | --- |
